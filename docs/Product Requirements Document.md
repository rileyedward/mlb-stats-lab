## Overview
I'm wanting to build a tool that I can use as a sort of MLB Stats Lab. It will be a data analytics tool that analyzes **Statcast** pitch-level data to analyze the current season and historical records as well.
### Technology Framework
We will leverage Python with mostly the usage of **Pybaseball**, which is a Python library that provides helper functions and tools to pull pitch-level data from **Statcast** and other baseball analytic sources into one, confined resource. Using this library in tandem with mainly **Jupyter Notebook** for writing out these analysis reports, but also libraries like **Numpy** and **Pandas** for those math and analytic things, but also other tools to help with rendering graphs and visualizations of things like basic graphs and spray charts for baseball.

Python3 for the version and then `uv` for the package manager and whatnot, we need to install this on my computer as I do not have this yet but that should be simple.

I do think most of the work will be done in Jupyter Notebook to aggregate these stats, but there should also be availability and code within here to generate some kind of final report into a PDF of some kind. These will be generated from templates where we provide specific information (e.g. a Series Matchup Report between two teams for a season), but that capability will have to be in here for generating PDFs.

- The project should be scaffolded out in such a way that it supports modern approaches for Jupyter Notebook projects using the other libraries and tools we're adding in.

For example, there would maybe be a `batting_line` function that takes in just the parameters of ALL the **Statcast** pitch data of some filtered down selection that you've made, and given some parameters to the function along with the **Statcast** data you've aggregated (probably with another helper function), you will be provided a batting stat line for those records. That's at least at a high-level that feature.
- After some brainstorming and deciding the types of templates we'd like to build, there should be some CLI commands in here to generate Jupyter Notebook templates for different scenarios. The one that jumps to my head immediately is the series matchup between two teams during the season. It would be a template of those two teams and the stats that are helpful for a series matchup in-depth. Again, these need to be brainstormed, but it should have the CLI commands and abilities to generate these. These templates will likely be the things that get generated out into those PDF reports, so as well...
- PDF reports should be able to be generated from specific templates and reports we're trying to make.
- Each helper function should include a doc-block comment above it that in-depth describes what this function does, and what it is used for and how to use it.
